### 1. Сравнительный анализ накопителей HDD и SSD

| Параметр | HDD | SSD |
| :--- | :--- | :--- |
| **Принцип работы** | Магнитная запись данных на вращающиеся жесткие диски с помощью подвижных считывающих головок | Электронная запись данных в микросхемы флеш-памяти типа NAND с помощью встроенного контроллера |
| **Скорость чтения/записи (примерно)** | От 80 до 200 МБ/с | От 500 МБ/с (SATA) до 3500–7000+ МБ/с (NVMe PCIe) |
| **Наличие движущихся частей** | Да (шпиндель, магнитные диски, блок головок) | Нет |
| **Устойчивость к ударам** | Низкая (чувствителен к вибрациям, падениям и сильной тряске во время работы) | Высокая (полностью невосприимчив к физическим ударам и падениям) |
| **Уровень шума** | Присутствует характерный шум, гул или треск при активной работе | Полностью бесшумный |
| **Цена за 1 ТБ** | Низкая (наиболее доступный вариант для хранения больших объемов данных) | Относительно высокая (дороже HDD в пересчете на один гигабайт) |
| **Срок службы / ограничения** | Ограничен механическим износом деталей; нет лимита на циклы перезаписи | Ограничен ресурсом циклов перезаписи ячеек памяти (параметр TBW — общая масса записанных терабайт) |
| **Пример использования** | Файловые архивы, сетевые хранилища (NAS), системы видеонаблюдения, хранение бэкапов | Системный диск для операционной системы, установка тяжелых программ, современных игр и баз данных |

### 2. Определение терминов оперативной памяти

1. **DDR (Double Data Rate)** - синхронная динамическая память с произвольным доступом и удвоенной скоростью передачи данных. Ее смысл заключается в том, что передача данных осуществляется дважды за один тактовый импульс системной шины — как по фронту (нарастанию), так и по спаду сигнала, что удваивает пропускную способность без повышения тактовой частоты.
2. **DIMM (Dual In-line Memory Module)** — двухсторонний модуль памяти. Это физический форм-фактор планок оперативной памяти, используемый в стационарных компьютерах, контакты на противоположных сторонах которого являются независимыми (в отличие от старого формата SIMM).
3. **Ранг (Rank)** - логический блок или область памяти, созданная из нескольких чипов на модуле, которые имеют ширину шины данных в 64 бита (или 72 бита с поддержкой ECC). Контроллер памяти может обращаться одновременно только к одному рангу на одном канале. Модули бывают одноранговыми (Single Rank), двухранговыми (Dual Rank) и четырехранговыми (Quad Rank).
4. **CAS Latency (CL)** - задержка сигнала выборки адреса столбца. Параметр показывает количество тактов шины памяти, проходящих с момента запроса контроллера до начала выдачи данных из конкретного столбца ячеек памяти.
5. **Тайминги** - задержки (выраженные в количестве тактов), необходимые контроллеру для выполнения базовых команд при обращении к ячейкам оперативной памяти. Они определяют время, нужное на открытие строки, выбор столбца, перезарядку и другие внутренние операции микросхем.
6. **Двухканальный режим** - режим работы архитектуры оперативной памяти, при котором контроллер задействует одновременно два 64-битных канала передачи данных, объединяя их в общую 128-битную шину. Он нужен для значительного увеличения пропускной способности подсистемы памяти, что напрямую повышает общую производительность процессора и встроенной графики.
